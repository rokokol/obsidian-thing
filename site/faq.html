Questions

The short answers

When an answer is not here, it is in the guide or in the issues

Do I need Obsidian running?

No. The server reads the vault directory from disk, and the app is needed for neither reading nor writing nor search

Does it work with Obsidian Sync?

The same way it works with any sync: the server sees what the directory holds. An outside change is noticed by the file watcher and by a periodic scan, and on Linux by inotify events as well

One exception is a concurrent write: a revision protects against what the server can see, not against another process writing the same file at the same moment

How safe is writing?

Writing is off by default. In a writable vault every edit carries a revision, replaces the file atomically, passes the vault rules and a trusted Python checker, and a refusal from any of them leaves the file as it was

What happens when two agents write at once?

One process serializes the edits and checks the revision before each one, so the second agent gets a refusal and reads the file again. Two processes on one vault break that: the check stops meaning anything. Run one process for each writable vault

Where does the token go?

Into the environment variable that token_env names. The configuration holds only that name. The Obsidian plugin keeps the token itself in Obsidian's secret storage and leaves only the secret ID in data.json

Do my notes reach a provider?

Not without an explicit permission. Vector search needs a provider, and a remote send needs allow_cloud and include_paths; only then does text leave the machine. Text search and metadata filters never call a model

Can I run it without embeddings?

Yes. A vault with state_dir and enabled = false gets full-text search, the filters and the whole link graph, but not related and map, which need vectors

Does it run on macOS and Windows?

The Python server runs anywhere, but the file watcher exists on Linux only. Other systems reconcile the index by periodic scans, and that is the only difference

Is there a mobile app?

No, and none is planned: this is a server, and the clients are an agent or the desktop Obsidian plugin. Mobile Obsidian cannot run the plugin
