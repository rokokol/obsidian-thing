Tools

Every tool, and the switch that offers it

The names and arguments below are checked against the server code on every test run, so the list cannot fall behind the build

One vault, several sets

A client sees only the tools that its vault's configuration allows. Reading is always on, writing only in a vault with writable = true, and the search tools only when state_dir is set

Always

These eleven exist in every vault. Each one applies the allowlist and refuses hidden paths and symbolic links

Reading and instruction tools
Tool Arguments Returns
obsidian.allowed—The allowed paths of the vault
obsidian.agentsmd—The first readable instruction file, with its revision
obsidian.skills_list—The name, description and SKILL.md path of each skill
obsidian.skill_readname, pathA file of the skill. path is SKILL.md by default
obsidian.memory_list—The memory notes with their type and revision
obsidian.memory_readnameOne memory note, or MEMORY.md
obsidian.readpathThe path, the content and the SHA-256 of the bytes
obsidian.statpathThe revision and the size, without the content
obsidian.links_outpathThe links with their target, anchor and status
obsidian.links_inpathThe backlinks, and the documents it could not inspect
obsidian.mediapathThe attachments: path, type, size. Never the bytes

Writing

Seven tools for a vault with writable = true. delete appears when a trash is configured, and the two memory writers work on the memory directory alone

Writing tools
Tool Arguments Returns
obsidian.writepath, content, expected_revision, all_warningsThe new revision and any warning
obsidian.updatepath, old, new, expected_revisionThe new revision after one replacement
obsidian.renamepath, new_name, expected_revisionThe new path, and the documents whose links changed
obsidian.deletepath, expected_revisionThe path and the trash identifier
obsidian.memory_writename, content, expected_revisionThe new revision of the note and of its line in MEMORY.md
obsidian.memory_deletename, expected_revisionThe path, the revision, the trash, and the new revision of MEMORY.md
obsidian.memory_index_writecontent, expected_revisionThe new revision of MEMORY.md

Each one refuses when the proposed text breaks a vault rule, makes YAML, Canvas or Base invalid, or when the checker rejects the change

Integrations

Eight tools, each behind its own switch. A structural edit applies as a batch: one failed step leaves the file as it was

Integration tools
Tool Arguments Returns
obsidian.canvas_editpath, expected_revision, changesThe document after the node and edge batch
obsidian.base_editpath, expected_revision, changesThe Base after its filters, formulas and views
obsidian.iconic_setpath, changesThe file's icon and colour
obsidian.fsrs_listafter, limitThe dictionaries after a path, and the next cursor
obsidian.fsrs_readpath, offset, limitThe cards, their cells and their FSRS state
obsidian.fsrs_historypath, card_id, offset, limitThe recorded review grades
obsidian.fsrs_editpath, expected_revision, changesThe document after created, updated and deleted rows
obsidian.excalidraw_renderpath, widthA PNG of the saved drawing

Search

Six tools for a vault with state_dir. related and map need an embedding profile, and the server hides map from every client except the plugin

obsidian.map

obsidian.map never reaches an agent's context: the server drops it from tools/list and answers a direct call with Unknown tool unless the client sends X-Obsidian-Thing-Client: plugin. The plugin sends that header and an agent does not, so the map stays outside the model's context: the plugin sees 32 tools and an agent sees 31

Search tools
Tool Arguments Returns
obsidian.indexpathThe revision and the number of indexed fragments
obsidian.querytext, limitThe matches per file, and the provider-failure flag
obsidian.findtags, aliases, properties, alias_property, filename_regex, limitThe paths, in path order
obsidian.status—Coverage, the queue, the profile, the last scan and the cost
obsidian.relatedpath, limit, min_score, section_line, include_paths, mime_types, exclude_linkedThe neighbours by score, one entry per file
obsidian.mapThe same as relatedThe same files, plus coordinates and the explained share
