Search that stays with you

The text index works with no model and no network. Vectors appear only when a provider is switched on, and a remote send needs one more permission on top of that

Canonical source: docs/semantic-search.md

The state directory

The index lives in a private directory outside the vault, owned by the server user, with no permission for group or other

  • search.sqlite3 holds the full-text index, the vectors and the text of the indexed notes
  • spend.sqlite3 holds the call journal: tokens, latency, status and cost
  • The index rebuilds from nothing, the journal does not: keep it

Text without a model

obsidian.query searches words through FTS5: underscores stay inside a token, so section_chunks is found, and it does not reduce Russian words to their base form

The result is one entry per file, with its section and line range. The score is a rank, not a cosine: text and vectors combine through reciprocal rank fusion

Metadata without embeddings

obsidian.find filters the indexed notes by tag, alias, property and file name, and never calls a model

  • A tag matches its descendants: project finds project/obsidian, but not projects
  • A null value checks presence alone: null finds the notes that carry the property
  • filename_regex matches the file name with its extension, without folders, under a time limit

Vectors and providers

The embedding providers
Provider Endpoint What to set
ollamaLocal, 127.0.0.1:11434 by defaulturl
lm_studioLocal, 127.0.0.1:1234/v1 by defaultbase_url, request_dimensions
openaiYour own compatible address over HTTPSbase_url, key_env
openrouterThe fixed OpenRouter endpointroute, key_env, zdr, data_collection

HTTP is allowed on loopback only, everything else needs HTTPS, and the server follows no redirect. Vectors are separated by a profile: the provider, the address, the model, the route and the dimensions

Attachments

Only text is indexed by default. Images, PDF, audio and video join allowed_mime_types one type at a time, and only a Gemini route through Vertex accepts them

Permission to send

allow_cloud is off by default, and a remote provider stays silent until include_paths names what may leave the machine at all

If the provider fails, obsidian.query returns the text matches and sets vector_unavailable instead of returning nothing

Cost

The budget caps the local estimate for one UTC day and applies to every remote call of the vault, the queue included. A vector cache hit never spends it

How the journal classifies a price
Kind Meaning
reportedThe price came from the provider
estimatedThe price follows the configured rate and the token count
unknownNo usable price, and it never lands in a sum
localA local route, with no charge

With a budget set, a call whose cost has no estimate is refused, and so is every call after one with an unknown cost

The index status

obsidian.status answers without reading any note: the coverage of the last full scan, the queue, the model profile and the cost by period and by day. Local hits and a confirmed price stay separate from an estimate

What stays out of the index

  • The patterns of indexing.exclude and, on request, the vault's .gitignore
  • Hidden paths and symbolic links, always
  • Excalidraw drawings and FSRS Vocabulary dictionaries, even with their integrations on

The map in the plugin

obsidian.map hides from every client except the plugin: the server requires the header X-Obsidian-Thing-Client: plugin. The header selects an interface and never replaces the token
